# Triage Labels

| 역할 | GitHub 라벨 | 의미 |
|---|---|---|
| needs-triage | needs-triage | 검토 필요 |
| needs-info | needs-info | 추가 정보 대기 |
| ready-for-agent | ready-for-agent | 명세 완료, 에이전트 구현 가능 |
| ready-for-human | ready-for-human | 사람이 구현해야 함 |
| wontfix | wontfix | 진행하지 않음 |

스킬이 역할을 언급하면 이 표의 GitHub 라벨을 사용한다.
